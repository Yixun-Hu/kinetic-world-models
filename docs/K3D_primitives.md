# Kinetic 3D primitives

These opt-in building blocks target a 33×33 torus with a 19×17 observation
box at `(row, column) = (7, 16)` and a 177-cell cone. They do not integrate
the FloWM-3D backbone or change the existing 2D defaults.

## Named velocities and static pinning

`kwm.collision.named_nodes("v5" | "v9" | "v17")` returns fp32 `[V,2]`
velocities in `(vx,vy)` order, with `(0,0)` first. v5 follows FloWM-3D's
zero,+x,+y,−x,−y order; v9 is zero followed by vx-major `{−1,0,1}²`;
v17 is zero followed by the four C4 orbits generated by `(.25,.25)`,
`(.75,.75)`, `(.25,.75)`, `(.75,.25)`, in that order. Every set is closed
under `rotation_perms` and `reflection_perms`.

Use `--lattice v17` with `--model adaptive` (or `spectral`), or
`KineticWM(kind="adaptive", lattice="v17")`. `build_model` restores both
new options from saved arguments. `--lattice grid` remains the default and
uses the unchanged `lattice_nodes` constructor and ordering.
`--pin_static [on|off]` defaults off for grid and on for named sets; the
Python option is `pin_static: bool | None`, with `None` selecting that default.
Pinning zeroes rho, evidence, and lock metadata for the zero lattice node
and blocks their update gradients in both LK and lock, including frozen
prediction steps. Feature memory and observation imprints still evolve.
An explicit grid pin also finds its zero node, which is not index zero.

The design note's claim that 2D already pins zero was incorrect: neither
existing adaptive update did so. Pinning is new; the default grid retains
its previous behavior and checkpoint keys. The existing `rot_state` needs
no change for named sets, but still acts on PR6 **orientation channels** and
square snapshots. Scalar-channel 3D turn handling remains backbone work.

## Scalar C4 convolution

`kwm.gconv.C4SymmetricDepthwise(channels, init="identity")` is a bias-free,
circular, depthwise 3×3 convolution. Its trainable `weight[C,3]` contains
centre, edge, corner values; `kernel()` expands them to `[C,1,3,3]` each
forward. Identity initialization is exactly the identity. There are `3*C`
parameters. `from_free_kernel(weight[C,3,3])` averages each four-element
spatial orbit, equivalent to averaging four rotated free kernels.
The kernel is exactly C4-invariant, hence the convolution is equivariant
in exact arithmetic; fp32 tests bound rotation error by `1e-6`. These are
scalar channels, with no orientation permutation or p4 channel mixing.

## Box and mask measurement

```python
from kwm.lock_nodes import lock_measurement, measure_nodes

velocity, evidence, locked = measure_nodes(
    previous, current, nu, lattice, action,
    world=33, dt=1.0, box=(7, 16), support_mask=cone,
    sigma=1.0, radius=None, static_residual=True,
)
```

Snapshots are `[B,K,Hb,Wb]`, `nu` is `[B,V,2]`, and `cone` is bool
`[Hb,Wb]`. `world` accepts an integer or `(H,W)`. `box` is the snapshot's
top-left `(row,column)` on that torus, including seam-crossing boxes;
`None` means origin placement. `action[B,2]` is camera displacement, so
transport uses `nu*dt - action`. `lock_measurement` returns displacement
residual `delta[B,V,2]`, evidence `[B,V]`, and fp32 lock bits `[B,V]`;
`measure_nodes` only converts delta to `nu + delta/dt`.

`support_mask=None`, `sigma=2.0`, `radius=6`, `static_residual=False`,
`box=None`, and `c4=False` preserve the original square-window results
bit-for-bit. Gaussian radius `None` means `ceil(3*sigma)`. These options
control SSD aggregation; LK retains its 5×5 sigma-1 Gaussian.
For direct `LocalSearch` calls, use `sigma` and `gaussian_radius`:
its existing `radius=1.0` argument still selects candidate range ±1
(or ±1.5), in half-cell increments.

The opt-in geometry path zeroes unobserved snapshot pixels before FFT,
transports bilinear support without Fourier ringing, and intersects it
with current support. A one-pixel erosion excludes LK differences across
mask and box borders; invalid terms are zero before Gaussian aggregation,
which is normalized by valid mass. Erosion handles arbitrary cone edges,
where rectangular replicate padding alone would not. Texture references,
coherence scale, and LK trace/damping means use valid support per node.
Search weights also intersect candidate validity. An empty support gives
zero evidence. The legacy unmasked path retains its old border arithmetic.

`static_residual=True` requires `lattice[0] == (0,0)` and measures
`(m_i-m_0, current-m_0)`, where `m_0` uses ego motion only, regardless of
`nu_0`. Node zero is excluded. A residual must exceed
`32 * fp32_epsilon * max_pixels(norm_channels(m_0))` to carry evidence;
this removes FFT roundoff in a background-only pair. This is a new,
scale-relative numerical floor, not a learned motion threshold.
The target background cancels when the observations match ego-only
transport. For moving hypotheses, `m_i-m_0` can still contain shifted
background texture; this residual construction is not a universal
background decomposition or an accuracy guarantee for arbitrary scenes.
Partial observations and fractional Fourier ringing can also leave
residuals when new background enters the cone.

Each snapshot bank uses one forward FFT, including the extra ego-only
phase; search shares one current-snapshot FFT. The bounded geometry cache
keys world shape, box shape/offset, candidate radius, device, and mask
values. Constructing a masked search key copies mask values to CPU
(a synchronization if a future caller supplies a GPU mask).
Gates, search, clustering, and selection stay detached; only selected,
locked LK displacements receive estimator gradients, as before.

Tests cover exact legacy parity, named-set construction and 2D smoke
rollouts, static pinning, C4 actions, convolution, rectangular seam
transport, masking and gradients, all three Gaussian widths, and static
and ego-motion nulls. The synthetic one-cell textured blob at `(0.3,-0.6)`
has velocity error below 0.1 cells/step; real 3D lift kill tests remain
necessary before choosing this estimator for training.
